## 🌟 Key Features

## 🚀 How to Run

### Method 1: Direct Browser Access
Simply double-click `index.html` or `dashboard.html` to open in any web browser (Chrome, Edge, Firefox).

### Method 2: Local PHP Server
Run in PowerShell or Command Prompt:
```powershell
cd "D:\Websites\CPA site shimu"
php -S localhost:8000
```
Then navigate to: `http://localhost:8000`

### Demo Login Shortcut
- Click **"Login Now"** on the landing page or open `login.html`.
- Click the **"Instant CPAGrip Dashboard Login"** button to jump directly into the full dashboard!
